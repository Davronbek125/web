* **Frontend:** Next.js (React 19), TypeScript, Tailwind CSS, Shadcn UI, Framer Motion
* **Video Player:** Video.js / Shaka Player (HLS / DASH adaptiv oqim)
* **Backend:** NestJS / Go, PostgreSQL, Redis, Meilisearch
* **Video Infratuzilmasi:** FFmpeg Transcoding Pipeline, S3 Storage, Cloudflare CDN
* **To'lov Tizimlari:** Click, Payme, Uzum Bank
* **Admin Dashboard:** TMDB orqali 1 tugmada filmlar qo'shish, seriallar ierarxiyasi, izohlar moderatsiyasi va rasmiy javoblar, jonli daromad va tomoshabinlar analitikasi
